# TestCraft 브랜드 자산

- 확정안: 2026-10-23 사용자 승인, 로고 후보 02번 ‘시험지의 설계도’.
- 의미: 시험지·도형·제도 도구를 통해 교사의 정교한 출제 설계를 표현합니다.
- 캐치프레이즈: **Crafting assessments with purpose.**
- 한국어: **평가의 의도를 담아, 시험을 빚다.**
- `testcraft-master.png`: 내장 이미지 생성 도구로 제작한 승인 원본입니다.
- `icon-*.png`, `favicon.ico`: 원본의 여백과 크기만 출력에 맞춰 변환합니다.
- `testcraft.svg`: PNG를 포함하는 SVG 래퍼입니다. 편집 가능한 순수 벡터 원본은 아닙니다.
- 재생성: 저장소 루트에서 `node tools/build_brand_assets.cjs`.

작은 파비콘에서도 사용자가 승인한 시험지·제도 도구 구성을 유지합니다.
