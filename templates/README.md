# templates — 양식

회차가 바뀌어도 그대로 쓰는 **재사용 자산**이다.

| 파일 | 쓰임 |
|---|---|
| `학교양식_예시.hml` | **문항지 서식의 원본.** HEAD(글꼴·문단·여백)와 표를 여기서 복제한다 |
| `문항카드-템플릿.xlsx` | 빈 문항 카드. 번호·배점·수식 서식이 들어 있다 |
| `출제계획서-템플릿.md` | 출제 계획서 |
| `평가문항-템플릿.md` | 문항 원고 |
| `해설지-템플릿.md` | 해설지 |
| `문항검토보고서-템플릿.md` | 문항 검토 보고서 |
| `수업피드백-템플릿.md` | 수업 피드백 보고서 |

## 학교양식_예시.hml

**이 파일이 없으면 문항지를 만들지 말 것.** 서식을 직접 짜면 한글이 파일을 열지 못한다.

파일 안에 학교의 작성 규칙이 적혀 있다 — 문항 번호 신명조 13pt 굵게 기울임 / 본문 신명조 11pt /
자간 0% 장평 100% / 첫 줄 내어쓰기 8.3pt / 줄 간격 160% / 답안은 표 양식 / 정답에 노란 형광펜.

학교 서식이 바뀌면 **이 파일만 교체**한다. `gen.py` 는 HEAD와 표를 이 파일에서 읽으므로
스크립트를 고칠 필요가 없다.

## 문항카드-템플릿.xlsx

`tools/new_exam.py` 가 새 회차의 `02_card/문항카드.xlsx` 로 복사해 준다.
배점표(3.2~5.1, 합 100)와 하8·중8·상8 구성이 들어 있다. 배점을 바꾸려면 이 템플릿을 고친다.
