TestCraft 1.1.0 — 처음 실행하기

이 설치 파일에는 앱, 내장 Python, Sharp가 포함된 Node.js, 공식 Windows x64 OpenAI Codex CLI와 네이티브 샌드박스 도구가 들어 있습니다. Python이나 Node.js를 따로 설치하지 않아도 됩니다.

AI 기능을 사용하려면 Codex를 사용할 수 있는 ChatGPT 구독으로 첫 실행 때 로그인해야 합니다. 앱에서 Codex 로그인을 시작한 뒤 브라우저에서 인증을 마쳐 주세요. 앱은 API 키를 요청하지 않습니다. Codex 계정과 서비스 사용은 OpenAI의 계정 조건을 따릅니다.

학생용·교사용 HWPX 시험지 출력과 수식 크기 재계산, 신명 중명조 한글 텍스트 레이어에는 Windows용 한컴오피스 한글이 필요합니다. 앱이 별도의 한글 창을 숨겨 내부 HML을 열고 HWPX로 저장합니다. 한글 프로그램과 해당 글꼴은 포함하지 않습니다. 한글 없이도 문항 설계·검토와 지원되는 그림 편집은 진행할 수 있습니다.

시험 작업물은 Windows 사용자 프로필에 저장되어 앱 업데이트 후에도 유지됩니다. TestCraft를 삭제해도 작업물은 삭제되지 않습니다.
