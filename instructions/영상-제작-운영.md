# TestCraft 영상 제작과 운영

## 제작 원칙

튜토리얼 7편은 한국어 설명·자막, 실제 UI 조작, 공개용 예제로 구성한다.
실제 Codex 생성과 한글 HWPX 변환을 사용한다. 생성 대기는 편집으로 단축하며 화면에 명시한다.
개인 인증 화면과 교사의 기존 시험은 녹화하지 않는다. 계정 로그인 화면 생략을 설명한다.

`tools/media-script.json`이 대본 원본이다. 촬영은 `tools/capture_media.cjs`,
음악·효과음·음성은 `tools/build_media_audio.py`, 편집은 `tools/render_media.py`로 재현한다.
미디어 제작 의존성은 `tools/media_requirements.txt`이며 앱 설치 의존성과 분리한다.

## 음악

Quiet Precision은 외부 샘플 없이 직접 합성한 오리지널 곡이다.
D minor의 D–F–A–E 짧은 선율, 전자 피아노·패드·베이스와 절제된 하우스 리듬을 공유한다.
튜토리얼 108 BPM, 홍보 리프라이즈 128 BPM. 보컬은 없다.
숏츠는 16마디 30초, 홈페이지 반복 영상은 8마디 15초로 편집한다.
클릭·스냅·완료 효과음도 같은 합성 음색을 사용한다.

음악과 효과음은 CC BY 4.0으로 공개한다. 표기: TestCraft / sehunYang.
소스 코드는 프로젝트의 AGPL-3.0을 따른다. 폰트 등 제3자 구성 요소의 기존 라이선스는 유지한다.
한국어 설명 음성은 `ko-KR-SunHiNeural` 합성 음성이다. 목소리 복제나 실제 인물의 녹음은 사용하지 않는다.

## 촬영과 검수

1. `tools/serve_media_studio.py`로 `.runtime/media-production/exams`만 사용하는 실제 앱을 숨김 실행한다.
2. Playwright의 녹화로 실제 조작을 캡처한다. 커서와 챕터 이름은 녹화 안내용 오버레이이다.
3. 원본 WebM과 장면별 시각, 원본 해시를 보관한다. 예제의 승인·생성 결과를 임의로 위조하지 않는다.
4. 설명 중 멈춘 화면은 마지막 실제 프레임을 유지한다. AI 생성 대기는 단축 표시한다.
5. 음성 발화 시각을 기준으로 VTT/SRT 자막을 만들고, 사용자가 자막을 끄거나 크기를 바꿀 수 있게 한다.
6. 7편 전부의 영상 디코딩, 음성·음악, 자막 시각, 개인정보 노출 여부와 실제 출력물 3개를 확인한다.

## 배포

큰 MP4와 음악은 GitHub의 `media-v1` 미디어 릴리스 자산으로 배포한다.
앱과 홈페이지에는 포스터·자막·카탈로그를 포함한다. 홈페이지의 작은 무음 반복 영상만 Pages에 포함한다.
미디어 릴리스는 사전 릴리스로 표시해 앱의 최신 안정 설치 파일 선택에 영향을 주지 않는다.
URL 변경 시 `app/static/tutorials-manifest.json`과 `docs/media/catalog.json`을 함께 갱신한다.
화면이 바뀌면 관련 챕터를 다시 녹화한다. 기존 미디어 자산은 임의로 덮어쓰지 않는다.

## 도움말

옆 패널은 현재 단계·검토 탭·그림 세부 단계에 따라 영상과 챕터를 제안한다.
직접 고른 영상은 현재 화면 안내를 누를 때까지 유지한다. 소리 자동 재생은 하지 않는다.
화면 안내는 실제 요소를 강조할 뿐, 클릭·저장·생성·승인을 대신하지 않는다.
화면 이동이나 종료 시 강조를 해제한다. 영상 연결 실패 시 글 안내와 외부 링크를 제공한다.
홈페이지 배경 영상은 무음 반복이며 일시정지, 화면 밖 재생 중지, 동작 줄이기 설정을 지원한다.
