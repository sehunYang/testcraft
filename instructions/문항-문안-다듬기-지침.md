# 문항 문안 다듬기 지침

> 2026-09-09. 초안(에이전트 생성)과 **출제 교사가 직접 손본 결과**를 문항 24개 전체에 대해
> 대조하여 뽑아낸 규칙이다. 문항의 물리 내용이 맞더라도 이 규칙을 어기면 반드시 손을 봐야 한다.
> **문항을 작성한 직후, 문항지로 내보내기 전에 이 문서를 처음부터 끝까지 적용한다.**

---

## 1. 지문이 답을 떠먹여 주지 않는다 ★ 가장 많이 지적된 항목

초안이 반복해서 저지른 잘못은 **친절함**이다. 개념을 묻는 문항의 자료에 그 개념의 정의·공식·
수치를 함께 적어 두면, 학생은 개념을 몰라도 자료를 읽어서 답한다. 문항의 성취기준이 평가되지
않고 자료 독해력만 평가된다.

실제로 삭제된 것들:

| 문항 | 삭제된 문장 | 그대로 두면 |
|---|---|---|
| 2 | "지구의 탈출 속도는 약 11.2 km/s이고, 달의 탈출 속도는 약 2.4 km/s이다." | (나) 답을 지문이 알려 준다 |
| 9(구) | 표의 **공전 주기** 열 | ㄱ·ㄴ이 표 읽기로 풀린다 |
| 11 | "중력이 **원의 중심을 향하는 힘, 즉** (ㄱ)의 역할" | (ㄱ)=구심력의 정의를 알려 준다 |
| 20 | "※ 공전 주기의 제곱은 긴반지름의 세제곱에 비례한다." | 케플러 제3법칙을 알려 준다 |
| 22 | "즉, A와 B가 한 바퀴를 도는 데 걸리는 시간은 각각 12초, 3초이다." | 주기를 직접 준다 |

**점검 절차**: 문항을 완성한 뒤 자료·문두를 다시 읽으며, 각 문장이 없어도 정답을 낼 수 있는지
확인한다. **없어도 풀리는 문장은 남기고, 그 문장이 있어야만 풀리는 문장은 지운다.**
지우면 난도가 오르므로, 지운 뒤 난도·배점·배치를 반드시 다시 계산한다.

## 1.5 아이디어 원문의 물리 상황을 바꾸지 않는다 ★ (2026-09-10 사고)

문항 카드의 아이디어 칸에 적힌 문두는 **출제 교사가 설계한 물리 상황**이다.
살을 붙일 때 문장을 다듬는 것은 되지만, **상황 자체를 바꾸면 다른 문항이 된다.**

실제 사고: 원문의 `높이가 $h$인 점 $p$` 를 에이전트가 `높이가 $h$인 **최고점** $p$` 로 고쳐 썼다.
- 원래 설계: $p$는 올라가는 도중의 한 점 → $v_y$가 양수에서 출발해 $t$에서 0(최고점), $4t$에서 $-3gt$
- 바뀐 문항: $p$가 최고점 → $v_y$가 0에서 출발
두 문항은 그래프 모양도, 풀이도 다르다. 정답이 우연히 맞아떨어져 검산으로도 걸러지지 않았다.

**점검 절차**
- 문두를 쓴 뒤 아이디어 원문과 **한 문장씩 대조**한다. 특히 `점 / 최고점`, `정지 / 등속`,
  `무시한다 / 작용한다` 처럼 **한 단어가 물리 상황을 바꾸는 말**을 확인한다.
- 원문에 없던 수식어(최고점, 가만히, 마찰 없이 …)를 **추가하지 않는다.**
- 그림 프롬프트도 원문 상황에 맞춰 쓴다. 그래프의 절편·교점처럼 **풀이에 쓰이는 값은
  프롬프트에 반드시 명시**한다(이 문항에서는 "$v_y$의 출발값이 $v_x$와 같은 높이").
- 프롬프트에 마크다운 강조(`**...**`)를 쓰지 않는다. 한글에서 별표가 그대로 찍힌다.

## 2. 군더더기 조건을 지운다

정답에 영향이 없거나 그림·그래프에서 자명한 조건은 삭제한다.

- 14번 "연직 위 방향을 (+)로 하며, 공은 던져진 후 지면에 도달한다." → 그래프에 다 있다
- 12번 "대기의 질량은 무시한다" → 계산에 쓰이지 않는다
- 21번 "필요하면 √3 = 1.7을 이용한다" → 답지가 무리수 꼴이라 근사값이 필요 없다
- 17번 "상자와 A는 트럭에 대해 정지해 있으므로 **트럭과 같은 가속도로 운동한다**" → 앞 절의 반복
- 4번 그림 프롬프트 "오른쪽 초점은 작은 ×로만 표시되어 있다" → 문항과 무관한 작화 지시

**조건은 상황 설정으로 흡수한다.** "외력을 무시한다", "중력을 무시할 수 있는" 대신
**"우주 공간에서"** 한 마디로 대체한다(7번, 13번).

## 3. 선택지·보기의 배열 순서

### 3.1 단일 정답형 선택지 — 짧은 것부터 긴 것 순
3번, 4번이 이 원칙으로 통째로 재배열되었다. 글자 수가 비슷하면 개념의 전개 순서를 따른다
(5번: 운동 방향과 **평행 → 수직 → 비스듬**).

### 3.2 합답형 보기 — 풀이 순서대로 ㄱ→ㄴ→ㄷ
19번: ㄱ 가속도가 같다 → ㄴ 가속도의 값 → ㄷ 마찰력의 값.
앞의 보기가 뒤의 보기를 푸는 발판이 되도록 놓는다. 길이도 대체로 짧은 것부터가 된다.

### 3.3 자료 속 항목은 같은 범주끼리 묶는다
1번: ㄱ 쥐불놀이 · ㄴ 회전목마(둘 다 원운동) · ㄷ 야구공(비원운동).
초안은 원운동 사이에 비원운동을 끼워 두었다.

### 3.4 배열을 바꾸면 답 번호가 바뀐다
정답 번호와 **형광펜 위치**를 반드시 함께 옮기고, 문항 카드의 `답` 열도 고친다.
합답형은 답지 조합 세트 자체를 바꿔 정답 번호를 원하는 자리에 놓을 수 있다
(1번: `{ㄱ},{ㄴ},{ㄱ,ㄷ},{ㄴ,ㄷ},{ㄱ,ㄴ,ㄷ}` → `{ㄴ},{ㄷ},{ㄱ,ㄴ},{ㄱ,ㄷ},{ㄱ,ㄴ,ㄷ}`).

## 4. 방향은 좌표축으로 쓴다

"위쪽 방향", "오른쪽으로" 같은 화면 기준 표현 대신 **$+x$, $+y$, $-y$** 로 쓴다.
7번(가스 $-y$, 로켓 $+y$), 13번($+y$), 16번($+x$)이 모두 이렇게 바뀌었다.
단, 그림에 좌표축이 없고 일상적 장면이면 "오른쪽으로"를 그대로 둔다(17번).

## 5. 단서 조항의 표준형

```
(단, 중력 가속도의 크기는 g이고, ○○과 △△는 무시한다.)
```

- **주어지는 값이 먼저, 무시 조건이 나중**(18번이 이 순서로 교정되었다)
- "중력 가속도는 $g$" → **"중력 가속도의 크기는 $g$"** (벡터/스칼라 구분)
- 조건은 문두가 아니라 단서 조항에 모은다(19번: 마찰 조건을 단서로 이동)
- 여러 개를 늘어놓기보다 하나로 묶는다(12번: "각 행성은 구형이고 대기의 질량은 무시한다"
  → "각 행성은 완벽한 구형이라 가정한다")

## 6. 용어와 표기

| 쓰지 않음 | 씀 | 비고 |
|---|---|---|
| 퍼텐셜 에너지 | **위치 에너지** | 교과서 용어. 문항지 전체에서 통일 |
| 나란한 방향으로 | 평행하게 | |
| 직선 운동 | 직선운동 | 붙여 쓴다 |
| 속력 $v_0$**으로** | 속력 $v_0$**로** | |
| $a$에서가 $b$에서보다 | $a$가 $b$보다 | |
| A**의** 속도**의** 수평 성분 | A 속도의 수평 성분 | '의' 중복 회피 |
| ~에 대한 기사 | ~에 관한 기사 | |
| "로켓과 가스로 이루어진 **계**의 운동량" | "로켓과 가스의 운동량" | 불필요한 술어 |
| "속력 변화량은 크다" | "속력 변화량의 **크기**는 크다" | 부호 있는 양의 대소 비교 회피 |

**표 머리의 물리량과 단위는 슬래시로 나눈다**: `질량(지구=1)` → `질량 / (지구=1)`.

## 6.5 배점표는 출제 교사의 것이다 ★ (2026-09-09 지적)

`배점표(문항 번호 → 배점 → 하/중/상)`는 **선생님이 정한 고정 자료**다.
문항의 난도가 바뀌면 **문항을 배점 자리에 다시 배치**할 뿐, 배점 숫자·등급 구성·표기는 건드리지 않는다.

- 배점은 카드에 적힌 값을 **그대로** 찍는다. `4` → `[4점]`이지 `[4.0점]`이 아니다.
  (자릿수를 통일한다는 이유로 임의 변환하지 말 것.)
- 하8·중8·상8 구성과 24개 슬롯의 배점 값은 요청 없이 바꾸지 않는다.
- 바꾸는 것은 **어느 문항이 어느 자리에 오는가** 뿐이다.

**배점이 자리에 붙는가, 문항에 붙는가는 이유에 따라 다르다.**

| 순서를 바꾸는 이유 | 배점 |
|---|---|
| **난도 재추정** — 문항이 생각보다 쉽거나 어려웠다 | **자리에 고정.** 배점표는 난도순이므로, 문항이 옮겨 간 자리의 배점을 받는다 |
| **편집상 조정** — 문항 길이·쪽 배치 때문에 자리를 바꾼다 | **문항을 따라간다.** 난도가 바뀐 게 아니므로 자기 배점을 그대로 들고 간다 |

후자의 경우 번호순 난도가 역전하는데 **정상이다.** 억지로 다시 정렬하지 않는다.
어느 쪽인지 애매하면 출제 교사에게 묻는다.

## 7. 소재는 현실적으로

17번의 **트럭 → 버스**. 트럭 적재함에 사람이 앉아 있는 상황은 현실에서 위험하거나 불법이다.
문항 소재가 안전 수칙에 어긋나지 않는지 본다.

## 8. 지문 상자는 한 문단으로

에이전트는 문장마다 줄을 바꾸는 버릇이 있다. 실제 시험지의 글상자는 **문장을 이어 한 문단**으로
쓴다(2·3·11번). 문항 카드의 `(글상자)` 아래에는 **줄바꿈 없이 한 줄로** 적는다.

## 9. 물리량 나열은 표가 아니라 〈보기〉 상자

6번: `(표)`로 만든 자료가 〈보기〉 상자로 바뀌었고, 문두("그림은 …표이다.")는 삭제되어
발문이 "〈보기〉에서 …"로 시작하게 되었다.
보기가 4개 이상이면 `tools/gen.py`가 자동으로 **한 줄에 3개씩** 배치한다
(ㄱ~ㅂ 6개까지 지원).

7. 문항 카드에 반영 → `python tools/gen.py` → 한글에서 `tools/수식크기_재계산.py`
