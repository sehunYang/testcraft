## 실제 가져온 코드

SVG-Edit 커밋 `c44f061d2f9a626d2771cc931298af5a45522d87`을 고정했다. 원본 `packages/svgcanvas/core/math.js`, `history.js`, `LICENSE-MIT.txt`, `AUTHORS`는 `app/static/vendor/svg-edit/`에 보관한다.

- `math.js`: 변환된 경계 상자, 사각형 교차, 45도 각도 맞춤 계산을 사용한다. 상자 선택, 회전된 글씨의 경계, Shift+선 그리기에 연결했다.
- `history.js`: `UndoManager`의 명령 스택·undo/redo를 사용한다. 도형과 글씨 JSON을 함께 저장·복구하는 명령 어댑터를 추가했다.
- `tools/build_svg_edit_core.py`: 원본을 읽어 외부 모듈 import를 로컬 namespace/logger로 치환하고, DOM 속성 기록 전용 메서드를 제외한 명령 스택을 추출해 `studio-core.js`를 만든다. 원본 저작권과 MIT 고지를 보존한다.
- 전체 SVG-Edit 앱을 이식한 것은 아니다. 기존 승인·글씨 분리·안전한 SVG 저장 체계 위에 필요한 핵심 코드를 통합했다. 외부 CDN이나 npm 설치 후 실행 스크립트 없이 로컬에서 동작한다.

## 편집 기능

- 레이어 목록 / 중앙 캔버스 / 속성 패널. 배경 생성·기본 도형·격자 옵션은 접이식 준비 영역에 둔다.
- 도형과 글씨를 Shift+클릭 또는 드래그 상자로 함께 선택하고 이동한다.
- 선택 객체 정렬, 3개 이상 선택 시 같은 간격 배치. 단일 선택 정렬은 캔버스 기준이다.
- 스마트 정렬 가이드와 맞춤, Alt+이동으로 일시 해제. 기존 10칸 격자 맞춤을 켜면 격자를 우선한다.
- SVG 회전은 기본 15° 단위 맞춤과 각도 가이드를 제공한다. 크기 조절은 다른 객체의 가장자리/중앙 및 같은 너비·높이에 맞추며 반대쪽 손잡이를 고정한다. 위치·치수·회전 설정을 개별 제어하고 Alt로 일시 해제한다. 치수 비교는 회전된 객체를 포함한 캔버스 축 기준 경계 상자를 사용한다. 단일 객체 회전 스냅은 편집 변환 행렬의 각도를, 다중 선택 회전은 선택 묶음의 상대 각도를 기준으로 한다.
- 선·사각형·타원·펜으로 캔버스에 직접 그리기. Shift는 선의 45도 맞춤, 사각형·타원의 비율 고정에 사용한다.
- 기존 경로 끝점·곡선 제어점, 정확한 길이·너비·높이·회전, 묶기·풀기와 도형 스타일 편집을 유지한다.
- 글씨 크기·회전 손잡이, LaTeX/한글 내용 수정. 크기 드래그 중에는 미리보기를 확대하고 놓으면 실제 글꼴로 렌더링한다.
- 레이어 이름·잠금·표시/숨김, 같은 레이어 영역 안의 드래그 순서 변경. 글씨는 항상 도형 위에 유지되어 배경을 교체해도 보존된다.
- 그림·글씨 통합 실행 취소/다시 실행, 최근 80개 작업. 연속 글씨 입력은 묶는다. 새 배경이나 다른 문항을 열면 이력을 초기화한다. 새로고침 후에는 저장 결과만 유지한다.
- 선택·손 도구, Space+드래그, Ctrl+휠 확대/축소(25~400%), 넓게 편집.
- Ctrl+A/C/V/D/Z, Ctrl+Shift+Z, Delete, 방향키, Shift+방향키. 복사 버퍼는 같은 자료 그림 안에서 사용한다.

숨긴 글씨는 최종 PNG에서 제외하고 잠근 글씨는 표시한다. 레이어 메타데이터는 카드 JSON과 XLSX에도 보존한다. 이전 카드에 메타데이터가 없으면 기존 표시 상태와 승인 해시를 그대로 유지한다.

PNG/JPG의 객체 변환은 기존 흑백 윤곽 추적 방식이다. 사진을 의미 단위의 도형으로 분해하는 기능은 아니며, 맞닿은 선은 하나로 묶일 수 있다. 물리량·수식은 Latin Modern Math, 한글은 신명 중명조 렌더러를 계속 사용한다.

## 분포 넛지

문항 유형·난이도·정답은 해당 항목을 선택한 문항끼리 비교한다. 선택 완료 수가 항목 수의 2배 이상(유형 8, 난이도 6, 정답 10)이면 균등 분포 평균과 비교한다. 차이가 `max(1문항, 평균의 25%)` 이상일 때 주황 ‘↑ 많음’ 또는 파랑 ‘↓ 적음’을 표시한다. 초반 입력과 작은 차이는 중립색이다. 강제 배분 규칙이 아니며 출제 의도를 우선한다. 툴팁·접근성 설명에는 개수와 비율을 표시한다.

성취기준은 실제 카드에서 1회 이상 사용한 코드만 표시한다. 선택한 코드가 없을 때는 안내 문구만 보인다.
