  1. ㄱ. A의 가속도의 크기는 2.5 m/s²이다.
  2. ㄴ. 실이 A를 당기는 힘의 크기는 10 N이다.
  3. ㄷ. B의 역학적 에너지 감소량은 A의 운동 에너지 증가량과 같다.

      설치해서 사용하는 Windows 로컬 앱입니다. 실행하면 내 컴퓨터에서 웹앱 화면이 열립니다. 이 안내 사이트에서는 앱을 다운로드하고 사용 방법을 확인할 수 있습니다.

      API 키를 준비해야 하나요?

      설치 배포본은 내장 Codex CLI와 계정 로그인을 사용하므로 API 키가 필요하지 않습니다. Codex를 사용할 수 있는 유료 ChatGPT 계정이 필요하며, 이용 한도는 해당 계정의 서비스 조건을 따릅니다.

      한글 프로그램 없이도 사용할 수 있나요?

      문항 설계와 검토는 가능합니다. 최종 HWPX 시험지 변환에는 한컴오피스 한글이 필요합니다. 변환 시 앱이 별도의 숨김 한글 프로세스를 사용하며, 한글 프로그램과 신명 중명조 글꼴은 설치 파일에 포함되지 않습니다.

      시험과 문항은 어디에 저장되나요?

      새 설치의 작업물은 내 컴퓨터의 %LOCALAPPDATA%\TestCraft에 저장됩니다. 기존 Question Studio 데이터가 있으면 이전 위치를 유지합니다. AI 기능을 실행하면 선택한 문항 내용이 로그인한 Codex 서비스로 전달됩니다.

      새 버전은 어떻게 받나요?

      v1.2.5부터 앱이 켤 때와 하루 한 번 새 버전을 확인해 알려 줍니다. 알림에서 지금 업데이트를 누르면 설치 파일을 받아 검증한 뒤 설치하고 앱을 다시 엽니다. 시험 데이터는 그대로입니다. 무설치 ZIP은 이 사이트에서 새 파일을 받아 주세요.

      평가원 기출 문제가 앱에 들어 있나요?

      들어 있지 않습니다. 기출 변형에서 평가원 기출 받기에 동의하면, 내 PC가 평가원 공식 홈페이지에서 과학탐구 문제지를 직접 받아 문항별로 정리합니다. 문제의 저작권은 한국교육과정평가원에 있으므로 학교 시험 출제를 위한 변형 원본으로만 쓰고 다시 배포하지 마세요. 가진 문제를 캡처하거나 PDF로 올려 변형할 수도 있습니다.

      그림도 AI가 그리나요?

      두 가지 길이 있습니다. 과학 상황 그림·회로·그래프·입자 모형·세포·가계도와 지도는 AI가 장면을 명세로 적고 앱이 정해진 규칙으로 그립니다. 그래서 수와 비율이 문항 조건과 맞습니다. 그 밖의 그림은 AI가 직접 그리며, 그림 유형을 고를 수 있습니다. strict는 정한 규칙대로 정확하게, flexible은 자유롭게, mixed는 고정할 부분과 자유롭게 그릴 부분을 나눠 그립니다. 자유롭게 그리는 그림도 평가원 그림 문항처럼 검은 선과 회색 음영의 선화로 그립니다. 어느 쪽이든 글씨는 따로 옮길 수 있는 레이어로 들어가고, 교사가 확인하고 고친 뒤 확정합니다.

      AI가 만든 문항을 바로 출력하나요?

      교사가 문항과 정답·해설을 검토하고 배점을 확인한 뒤 전체 문항카드를 승인합니다. 실제 그림 제작은 승인 이후 진행하며, 완성된 그림도 최종 확인합니다. 출력한 시험지는 인쇄 전 배치와 수식을 확인해 주세요.
